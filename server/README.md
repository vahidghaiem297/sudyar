# راه‌اندازی بک‌اند محلی سودیار (نمونه‌ی مرجع)

این یک سرور کوچیک Node.js/Express است که دقیقاً نشون می‌ده «ورود واقعی با گوگل» باید سمت سرور چطور کار کنه: توکن گوگل تأیید می‌شه، کاربر در یک دیتابیس ذخیره می‌شه، و یک نشست (session) واقعی با کوکی امن ساخته می‌شه — به‌جای اینکه فقط توی مرورگر (که قابل جعله) اطلاعات خونده بشه.

## راه‌اندازی

نیازمندی: Node.js نسخه‌ی ۱۸ یا بالاتر ([nodejs.org](https://nodejs.org))

```bash
cd server
npm install
npm start
```

حالا کل سایت — نه فقط API — روی **http://localhost:3000** در دسترسه. دیگه لازم نیست از Live Server یا هر ابزار استاتیک دیگه‌ای استفاده کنید؛ همین سرور، هم فایل‌های سایت (index.html، login.html، …) رو سرو می‌کنه هم API رو.

## این سرور دقیقاً چیکار می‌کنه

1. `POST /api/auth/google` — توکن گوگلی که فرانت‌اند می‌فرسته رو با آدرس رسمی گوگل (`oauth2.googleapis.com/tokeninfo`) تأیید می‌کنه (امضا، انقضا، صادرکننده)
2. اگه معتبر بود، کاربر رو توی `db.json` پیدا می‌کنه یا (اگه اولین ورودشه) می‌سازه
3. یک نشست واقعی می‌سازه و به‌صورت کوکی امن (`httpOnly`) به مرورگر می‌ده
4. `GET /api/auth/me` — بر اساس همون کوکی، اطلاعات کاربر فعلاً واردشده رو برمی‌گردونه
5. `POST /api/auth/logout` — نشست رو باطل می‌کنه

فایل `js/auth.js` توی خود سایت از قبل طوری نوشته شده که اول همین بک‌اند رو امتحان می‌کنه؛ اگه سرور بالا نبود (مثلاً دارید فقط با یک static server ساده پیش‌نمایش می‌گیرید)، به‌صورت خودکار به همون حالت قبلی (خوندن توکن فقط توی مرورگر) برمی‌گرده — یعنی سایت همیشه کار می‌کنه، چه سرور رو اجرا کرده باشید چه نه.

## قبل از استفاده‌ی واقعی (پروداکشن) حتماً این‌ها رو انجام بدید

- **دیتابیس واقعی**: `db.json` فقط برای تست لوکاله. برای پروداکشن با یک دیتابیس واقعی (PostgreSQL، MySQL، MongoDB، …) جایگزینش کنید.
- **Client ID رو قفل کنید**: مقدار `GOOGLE_CLIENT_ID` بالای `server.js` رو با همون Client ID واقعی‌ای که توی `js/auth.js` گذاشتید پر کنید، تا سرور مطمئن بشه توکن واقعاً برای همین سایت صادر شده (الان چون هنوز دامنه نهایی نیست، این چک رد می‌شه).
- **HTTPS اجباریه**: کوکی نشست بدون HTTPS در خیلی از مرورگرها به‌درستی کار نمی‌کنه یا امن حساب نمی‌شه.
- **`db.json` رو private نگه دارید**: شامل ایمیل کاربرهای واقعیه؛ توی `.gitignore` هست ولی مطمئن بشید روی هاست نهایی هم در دسترس عموم نباشه.
